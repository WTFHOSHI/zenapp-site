# История изменений

## Версия 2.0

### Добавлено

- описание сайта в meta description для поисковиков
- иконка сайта (favicon) во вкладке браузера
- плавная прокрутка по якорям (scroll-behavior: smooth)
- адаптив для телефонов (media query до 768px)
- рамка фокуса для ссылок и кнопок для навигации с клавиатуры
- hover для кнопки "Скачать" в меню
- отступ у якорей, чтобы заголовки не прятались под шапкой

### Изменено

- язык страницы lang="en" заменён на lang="ru"
- цвет кнопки "Попробовать бесплатно" при наведении сделан темнее
- цвет выделенных слов в блоке "Начните свой путь" сделан светлым
- картинки переименованы понятными названиями (logo.png, hero-phone.png, icon-progress.png и т. д.)
- у картинок ниже экрана добавлен loading="lazy"
- ссылки на магазины открываются в новой вкладке (target="_blank" rel="noopener")
- в подвале добавлен знак авторского права
- кнопка скачать при наведении не заркывает текст

### Исправлено

- лишний символ ">" после <div class="store-buttons">
- пустые ссылки href="" в меню, в кнопках магазинов и в подвале
- пустые и одинаковые alt у картинок
- ссылки меню теперь ведут к нужным блокам (#features, #about, #cta)

### Удалено

- неиспользуемая картинка images/unnamed.png
